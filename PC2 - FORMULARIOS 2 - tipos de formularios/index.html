Elementos de un formulario web

HTML ofrece diferentes tipos de controles de formulario para que los usuarios puedan introducir, seleccionar y enviar informacion. Aqui tienes todos los tipos principales con ejemplos.

Campo de texto

Permite escribir una linea de texto <input type="text">

Contraseña

Texto oculto ppr seguridad <input type="password">

Correo electronico

Para direcciones de email <input type="email">

Numero

Permite introducir numeros <input type="number">

URL

Para direcciones web <input type="text">>

Busqueda

Campo de busqueda <input type="text">>

Fecha

Selector de fecha <input type="date">>

Hora

Selector de Hora <input type="date">>

Semana

Selector de semana <input type="week">>

Color

Selector de color <input type="color">>

Rango

Selector de Rango <input type="range">>

Chekbox

Casilla de verificaión <input type="Chekbox">>

Radio

Permite una unica seleccion <input type="Radio">>

Lista desplegable

Permite seleccionar una opcion en una lista <select>>

Lista de opcion

Permite seleccionar una opcion en una lista <select>>

Area de texto

Permite incluir texto en varias lineas <textarea>>
